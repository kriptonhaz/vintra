Add the tenant-facing `/spanduk/generate` page. Users pick the spanduk type (X-Banner / Spanduk Kecil / Spanduk Besar), choose a preset size or type a custom W×H in meters, fill the AI-background style fields (theme/style/palette/mood), and enter the text overlay (headline, subhead, phone, address) which is composited server-side for sharp print output. The result preview honors the actual spanduk aspect ratio and offers separate PNG and PDF download buttons.
